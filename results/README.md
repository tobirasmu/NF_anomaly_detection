# Results after training
In order to reproduce some of the result plots from the paper, the results will either have to be reproduced by running the corresponding experiments or by downloading the results into this folder.

For *iterative* results, they can be downloaded from [this page](https://drive.google.com/file/d/1hdGX94zVoRbdUw9j2DoA5EygTPgCLJfH/view?usp=share_link) and the ``running_results``-folder should be unzipped into the ``results`` folder. The folder includes embedded (z-space) values for every iteration along with the embedded (AE) values and the ``state_dict`` for the AE model.
