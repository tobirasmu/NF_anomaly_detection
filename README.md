# NF_anomaly_detection
Implementation of the paper "Anomaly Detection in Broadband Networks: Using Normalizing Flows for Multivariate Time Series"

## Download the GHL dataset
Before any analyses can be carried out, the data needs to be downloaded into the data folder. Please the ``README.md`` file in the data folder for instructions.

## Do you just want to recreate the plots?
See the ``README.md`` file in the ``results``-folder for how to download already run results.
