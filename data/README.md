# The GHL dataset

The GHL dataset should be put into a folder called "GHL" in one of tho ways:
- Download all the files from [here](https://kas.pr/ics-research/dataset_ghl_1) and run the ``load_GHL_data`` function with the ``saved=False`` argument.
- Download the preloaded and/or relabeled pickled files from [here](https://drive.google.com/drive/folders/1q5y2gkQHoDhTzAA3q9Mew-VptBxm4XVx?usp=share_link) and call the ``load_GHL_data`` function with the ``saved=True´´ argument.
